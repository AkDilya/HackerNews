# ДЗ №4 — Разработка Frontend-приложения с AI-агентом

**Проект:** TrendRadar — трекер технологических трендов на данных Hacker News и Dev.to
**Автор отчёта:** Frontend-разработка выполнена в паре с AI-агентом (Claude Code / OpenCode)

---

## 1. Инициализация проекта

### Стек

| Слой | Технология | Назначение |
|---|---|---|
| UI-библиотека | **React 18** | Компонентная архитектура, хуки |
| Сборщик | **Vite 5** | Dev-сервер (порт 5173) и production-сборка |
| Стилизация | **Tailwind CSS (через CDN)** | Utility-first классы, тёмная тема через `darkMode: 'class'` |
| Графики | **Chart.js / Recharts** | Линейные тренды, донат-диаграмма тональности, мульти-трендовое сравнение |
| Граф | **Vis-Network** | Интерактивный граф связей технологий с физической раскладкой |
| Роутинг | **react-router-dom v6** | SPA-навигация без перезагрузки страницы |
| HTTP | Fetch API (нативный) | Запросы к FastAPI-бэкенду на `http://localhost:8000` |

Tailwind подключён через CDN-скрипт в `index.html` — без этапа сборки стилей, что упростило инициализацию: проект запускается двумя командами (`npm install`, `npm run dev`).

### Роль AI-агента при инициализации

Проект инициализировался **с помощью AI-агента** (Claude Code / OpenCode). Агенту передавался файл правил `CLAUDE.md` с требованиями проекта (стек, структура каталогов, соглашения по коду), после чего агент:

- сгенерировал каркас Vite-проекта с конфигурацией `vite.config.js` и плагином `@vitejs/plugin-react`;
- создал точки входа `index.html`, `src/main.jsx`, `src/App.jsx` с маршрутизацией;
- подключил Tailwind через CDN с настройкой `darkMode: 'class'`;
- завёл зависимости `chart.js`, `react-chartjs-2`, `vis-network`, `vis-data`, `react-router-dom`, `recharts`.

Такой подход позволил получить рабочий «скелет» приложения за одну итерацию и дальше работать фичами, не тратя время на boilerplate.

## 2. Реализация структуры и компонентов

### Структура папок

```
frontend/src/
├── main.jsx              # Точка входа: рендер <App /> внутри <ThemeProvider> и <AuthProvider>
├── App.jsx               # Маршруты react-router-dom + боковое меню (Sidebar)
├── index.css             # Базовые стили
├── api.js                # Константы и хелперы запросов к API
├── components/           # Переиспользуемые компоненты
│   ├── ArticleCard.jsx   # Карточка статьи (рейтинг, комментарии, избранное, AI-саммари)
│   ├── TrendChart.jsx    # Линейный график упоминаний технологии по дням
│   └── SentimentChart.jsx# Донат-диаграмма распределения тональности
├── context/              # React Context — глобальное состояние
│   ├── AuthContext.jsx   # Авторизация: токен в localStorage, authFetch с Bearer-заголовком
│   └── ThemeContext.jsx  # Светлая/тёмная тема (класс `dark` на <html>)
└── pages/                # Страницы приложения (одна страница = один маршрут)
    ├── Dashboard.jsx     # Главная аналитика
    ├── Explorer.jsx      # Поиск и фильтрация статей
    ├── Graph.jsx         # Граф связей технологий
    ├── Compare.jsx       # Сравнение технологий на одном графике
    ├── Favorites.jsx     # Личный кабинет: избранное + подписки
    ├── Admin.jsx         # Админ-панель (KPI, очистка БД)
    ├── Profile.jsx       # Профиль пользователя (GitHub OAuth)
    ├── AuthCallback.jsx  # Обработка токена после OAuth-редиректа
    ├── Login.jsx         # Вход через GitHub
    └── About.jsx         # Описание проекта и стека
```

Принцип разделения: `pages` — «толстые» экраны, которые сами ходят в API; `components` — презентационные блоки без знания о маршрутах; `context` — сквозные concerns (тема, авторизация), доступные любому компоненту через хук `useAuth()` / `useTheme()`.

### Созданные страницы

- **Dashboard** — KPI-карточки (всего статей, топ-технология, тональность), график упоминаний выбранной технологии, донат-диаграмма тональности, виджет «💎 Скрытые жемчужины» (высокий рейтинг при малом числе комментариев), умная лента «🤖 Для вас», экспорт тренда в CSV.
- **Explorer** — постраничный поиск статей: текстовый запрос, фильтр по технологии, тональности и минимальному рейтингу, сортировка по дате/рейтингу/комментариям, кнопка «Загрузить ещё» (пагинация по 25 статей), подписка на технологию (🔔).
- **Graph** — интерактивный vis-network граф (см. ниже).
- **Compare** — сравнение 2–4 технологий на одном графике, окно 7/14/30/90 дней.
- **Admin** — вход по админ-ключу, KPI-статистика по базе, таблица статей с учётом источника (Hacker News / Dev.to), очистка БД.
- **Profile / Favorites (Личный кабинет)** — избранное пользователя, подписки с бейджем «+N новых», статистика аккаунта.

### Ключевые компоненты

**`ArticleCard`** — универсальная карточка статьи:
- счётчики ⭐ рейтинг и 💬 комментарии, дата, источник;
- кнопка ❤️ «в избранное» (видима только авторизованному);
- кнопка **«AI-саммари»**: по клику бьёт в `POST /api/trends/summarize/{id}`, показывает «Генерирую…», разворачивает краткое содержание статьи прямо в карточке; корректно обрабатывает недоступность Ollama («AI временно недоступен»);
- тёмная тема поддержана через классы `dark:`.

**`TrendChart` / `SentimentChart`** — обёртки над Recharts/Chart.js: `ResponsiveContainer` (график тянется за контейнером), кастомный tooltip, сетка и оси, согласованные с темой (светлой и тёмной).

**MultiTrendChart (график сравнения, страница `/compare`)** — мультилинейный график на Recharts: несколько технологий на одних осях, легенда-чипы для добавления/удаления линий (лимит 4), переключатель периода. Данные берутся из `GET /api/trends/compare?tech=A,B&days=14`.

**`Graph`** (страница Graph) — интерактивный граф на `vis-network/standalone`:
- узлы = технологии (размер ∝ числу упоминаний), рёбра = совместные упоминания (толщина ∝ силе связи);
- **кластеризация по категориям** (`AI`, `Web`, `Python`, `Database`, `DevOps`…): после стабилизации физики ноды сворачиваются в кластеры-категории с подписью `Python (3)`;
- **фокусировка на узле**: клик по технологии раскрывает её окружение, приглушая остальные узлы (`DIMMED_NODE_OPACITY`), и открывает боковую панель со статьями этой технологии;
- блок **«Похожие технологии»** — чипы-рекомендации из совместных упоминаний (`GET /api/trends/{tech}/similar`), клик перенацеливает фокус;
- двойной клик по кластеру раскрывает его технологии; клик по пустому месту сбрасывает фокус;
- две темы графа (светлая/тёмная) с приглушённой палитрой категорий; граф перестраивается при переключении темы.

## 3. Ключевые фичи (что было сделано с помощью AI)

Каждая фича ниже рождалась из короткой постановки задачи человеку, а реализация (код, состояние, запросы к API, краевые случаи) писалась AI-агентом с последующей проверкой в браузере.

### 3.1 Дашборд
- **KPI-карточки**: «Всего статей», «Топ-технология» (с количеством упоминаний), «Тональность» — данные из `GET /api/trends/summary`.
- **График трендов**: `TrendChart` упоминаний по дням + выбор технологии + экспорт выбранного тренда в CSV (Blob + `<a download>`).
- **Виджет «💎 Скрытые жемчужины»**: статьи с высоким score, но низким `descendants` — неочевидно ценный контент, который не попал на первую страницу HN.
- **Умная лента «🤖 Для вас»**: персональное ранжирование статей по подпискам, избранным технологиям и свежести (данные из `GET /api/feed`), с бейджами персонального рейтинга.

### 3.2 Граф связей технологий
- Интеграция **Vis-Network**: загрузка `GET /api/graph`, нормализация узлов/рёбер в `DataSet`, force-раскладка с отключением физики после стабилизации (иначе граф «плывёт» под курсором).
- **Кластеризация по категориям** через `network.cluster()` с `joinCondition` по полю `group`; кластерные узлы хранятся в `Map` для обратного раскрытия.
- **Фокус на узле**: пересчёт прозрачности узлов/рёбер (`setEdgeOpacity`, `DIMMED_NODE_OPACITY = 0.2`) — связанное окружение остаётся ярким, остальное гаснет.
- **Блок «Похожие технологии»** в панели справа — рекомендации строятся бэкендом по совместным упоминаниям.

### 3.3 Explorer
- **Поиск**: дебаунс-текстовый запрос к `GET /api/trends/search`, совместимый с пагинацией (`{ items, total }`).
- **Фильтрация**: по технологии (мультиселект-чипы), по тональности (positive/neutral/negative), по минимальному рейтингу.
- **Сортировка**: по дате / рейтингу / числу комментариев — переключается на бэкенде параметром `sort_by`.
- **Экспорт в CSV**: выгрузка статей/тренда файлом через Blob (используется и на Dashboard для графика тренда).
- **Пагинация**: кнопка «Загрузить ещё (N осталось)», корректная отмена запросов через `AbortController`.

### 3.4 AI-саммари
- **Интеграция с Ollama**: кнопка в `ArticleCard` → `POST /api/trends/summarize/{id}` → бэкенд обращается к локальной Ollama (`qwen2.5:0.5b`) и возвращает краткое содержание статьи.
- Фронтенд показывает состояние «Генерирую…», разворачивает результат в карточке, при недоступности LLM показывает fallback-сообщение — интерфейс не ломается без AI.
- Тот же LLM-стек на бэкенде извлекает из заголовков технологии и тональность, которыми наполнены фильтры Explorer и категории графа.

## 4. Тестирование и отладка

Отладка велась итеративно: ошибка воспроизводилась в браузере (или в консоли Vite), текст ошибки и контекст передавались AI-агенту, агент предлагал правку, правка сразу проверялась горячей перезагрузкой.

### Типичные исправления с помощью AI

| Проблема | Как проявлялась | Решение (найдено AI) |
|---|---|---|
| **CORS** | Фронт на `localhost:5173`, API на `localhost:8000` — браузер блокировал запросы | Настроить `CORSMiddleware` на бэкенде со списком разрешённых origins и `allow_credentials`; запросы фронтенда унифицировать через `authFetch` |
| **Физика графа** | Узлы «налезали» друг на друга, граф дёргался при наведении | Отключать физику по событию `stabilizationIterationsDone`, кластеризовать только после стабилизации, зум-границы `fit()` |
| **Синтаксис в App.jsx** | Белый экран после добавления маршрутов; в консоли `Unexpected token` | AI локализовал незакрытый JSX-тег/лишнюю запятую, восстановил структуру роутов |
| **Stale-состояние после HMR** | После правок палитры граф рендерил старые цвета | Полная перезагрузка страницы; для таких правок — пересоздание Network-инстанса в `useEffect` |
| **Гонка запросов** | При быстрой смене фильтров отображался ответ более раннего запроса | `AbortController` + отмена в cleanup-функции `useEffect` |
| **Токен после OAuth** | Редирект с `?token=...` не подхватывался | Отдельная страница `AuthCallback.jsx`, читающая токен из URL и кладущая его в `localStorage` |

### Пример промпта из практики

> «Помоги исправить ошибку отображения графа, когда узлы налезают друг на друга. Граф на vis-network, узлы — технологии с весом (упоминания), после кластеризации по категориям часть узлов сливается в один комок, а при наведении курсора физика снова включается и раскладка "плывёт". Хочу, чтобы после первичной стабилизации физика отключалась, кластеры строились уже на статичной раскладке, а повторное включение физики не ломало позиции».

Типовой ответ агента: перенести `network.cluster(...)` в обработчик `stabilizationIterationsDone`, вызвать `network.setOptions({ physics: { enabled: false } })`, а для «расползания» добавить `physics.solver: 'barnesHut'` с подобранными `gravitationalConstant` / `springLength`. Правка проверялась вживую скриншотом до/после.

Дополнительно AI использовался для **регрессионного обхода**: сценарий «открыть все страницы → проверить консоль браузера на ошибки → собрать production-бандл `npm run build`» выполнялся агентом после каждой крупной фичи, что ловило ошибки до сдачи работы.

## 5. Адаптивная вёрстка

Адаптивность реализована **исключительно утилитами Tailwind** — без отдельных CSS-файлов и media-запросов:

- **Сетка карточек**: `grid grid-cols-1 md:grid-cols-3 gap-6` — KPI-карточки и фильтры Explorer занимают одну колонку на мобильном и три на десктопе (`About` использует `md:grid-cols-4`).
- **Flex-раскладки**: `flex`, `flex-wrap`, `gap-*` — панели фильтров и чипы переносятся на новую строку на узких экранах; шапка графа — `flex items-center justify-between` с переносом подписи.
- **Условная видимость**: `hidden md:flex` — бейджи персонального рейтинга в умной ленте и второстепенные элементы скрываются на мобильных, чтобы не загромождать экран; боковое меню сворачивается в компактный вид.
- **Резиновые графики**: `ResponsiveContainer` (Recharts) и `w-full` у контейнера vis-network — графики растягиваются на всю ширину колонки при любом брейкпоинте.
- **Тёмная тема как вариант адаптивности**: `dark:` префиксы у всех поверхностей (`bg-white dark:bg-gray-800`, `text-gray-800 dark:text-white`) — интерфейс одинаково читаем в обоих режимах, переключение классом `dark` на `<html>`.

Проверка адаптивности выполнялась изменением ширины окна браузера (включая мобильную пропорцию) с контрольным просмотром Dashboard, Explorer и Graph на каждом брейкпоинте.

## Вывод

Frontend TrendRadar собран с AI-агентом от инициализации до финальной полировки: каркас проекта, 10 страниц, компоненты графиков и интерактивный кластеризованный граф, умная лента и AI-саммари через Ollama. Связка «человек ставит задачу и проверяет результат — AI пишет код и чинит ошибки» дала скорость, которую ручная разработка одного студента обеспечить не могла; при этом каждый результат проверялся вживую (консоль браузера, `npm run build`, скриншоты светлой/тёмной темы), поэтому качество не приносилось в жертву темпу.
